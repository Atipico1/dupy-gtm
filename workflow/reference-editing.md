# 레퍼런스 정밀 분석과 촬영본 편집 계약

사용자가 지정한 레퍼런스를 구조적으로 그대로 재현하고 Dupy 제품 내용으로 치환한다. 추상적인 훅/전개 요약만으로 제작을 시작하지 않는다. 기존 연구의 샘플 프레임 요약은 탐색용이며 아래 전체 분석을 대신하지 않는다.

## 재현 원칙

**포맷은 레퍼런스대로 옮기고, 내용과 Dupy 에셋만 바꾼다.** 원본에 없는 엔딩 카드·강조색·배경 박스·전환 효과를 임의로 추가하지 않는다. 승인된 차이가 있으면 원본/결과 타임코드와 `deviation_reason`을 남긴다.

### 훅은 유지하고 설명부에서 차별화

- 사용자가 레퍼런스를 그대로 따르라고 했으면 훅의 문구·첫 화면·표정/행동·자막 줄바꿈/위치·박자를 고정한다. 전용 캐릭터 등 사용자가 승인한 시각 자산 교체만 적용한다.
- 훅은 제품과 직접 관련 없어도 된다. 제품 적합성을 이유로 새 훅을 만들거나, 원본 훅에 제품명·쇼핑쇼츠·기능 설명을 끼워 넣지 않는다. 사용자가 훅 변경을 명시했을 때만 바꾼다.
- 쇼핑쇼츠라는 맥락과 제품 차별점은 훅 다음 설명/실제 데모/결과에서 보여준다. 후보가 필요하면 같은 훅 아래 설명부 구성을 비교한다.
- 기획에는 `locked_reference_hook`(원문·타임코드·화면/자막 근거·승인된 차이)과 `explanation_adaptation`을 나누어 기록한다. 리뷰는 원문 훅과 먼저 대조한다. 훅이 임의로 바뀌었으면 렌더 전에 수정한다.
- 원본의 성과 표현이 검증되지 않았으면 리뷰에 그 한계를 기록한다. 레퍼런스 수치나 타사 결과를 Dupy의 실제 수익·실적으로 확인됐다고 쓰지 않는다. 이 확인을 핑계로 사용자 지정 훅을 조용히 교체하지 않는다.

## 분석 필수 항목

레퍼런스 전체를 확인하고 shot마다 시작/끝 타임코드와 근거 프레임을 남긴다. 컷 경계·자막 변경점은 인접 프레임을 다시 확인한다. 확인하지 못한 치수/폰트/전환은 추정 또는 unknown으로 표시한다.

- 화면 구성·순서: 인물 크기/위치/시선/손 동작, 배경, 화면녹화·제품·인물의 배치와 전환 순서, 크롭/줌/화면비.
- 컷 전환: 각 컷 길이, 하드컷/점프컷/디졸브/줌, 전환 길이, 컷 전후의 동작/음성 연결.
- 자막: 실제 문구와 등장·퇴장 시각, 줄 수/강조 단어, 화면 기준 bbox(x,y,w,h;0~1), 텍스트 높이/화면높이 비율, 정렬·색·테두리·배경. 폰트 이름은 확인된 경우만 기록. 출력 해상도에 맞춰 비율로 환산한다.
- 내용: 말하는 주장/정보 순서와 그 순간 보여주는 증거·제품 동작을 연결. 자막·오디오 내용 불일치도 기록.
- 훅과 CTA: 첫 화면·첫 말·첫 행동의 조합, 기대/궁금증, CTA 시각·문구·동작·대상 링크/댓글 키워드.

각 원본 shot에 `dupy_replacement`를1:1 매핑한다. 유지할 화면·순서·컷·자막 규칙과 바꿀 제품/문구/실제 데모를 구분한다. 새로운 연출로 임의 대체하지 않는다. 원본의 허위/미검증 성과나 타사 UI를 Dupy 사실처럼 쓰지는 않는다. 차이는 `deviation_reason`으로 남긴다.

## 촬영본은 편집 재료

원본 영상은 수정하지 않는다. catalog의 preferred 상태와 사용 구간을 우선한다. archived 파일은 사용자가 재선택하거나 대표본에 필요한 장면이 없을 때만 검토한다. 이전 촬영본을 이동한 것은 파일 완전 중복 판정이 아니라 편집 목적의 테이크 정리다.

1. 선택된 레퍼런스의 shot별 목표 길이와 새 내레이션 타이밍을 확정한다.
2. 필요한 원본 구간만 자른다. 입력 실패·대기·반복 클릭·화면 이탈·촬영 종료 부분은 제외한다.
3. 원본의 **모든 오디오 트랙을 제거**한다. 다중 트랙도 포함한다. 새 고정 음성·의도한 음악/효과음만 최종 믹스한다.
4. 가변 배속/점프컷으로 장면별 길이를 맞춘다. `배속=선택 원본 구간 길이/목표 재생 길이`를 시작점으로 계산한다. 핵심 주소·클릭·결과는 읽을 시간을 남기고 불필요한 이동/대기만 더 빠르게 한다.
5. 짧은 원본을 억지로 느리게 늘리지 않는다. 필요한 경우 승인 기획에 맞는 마지막 프레임 홀드·다른 사용 구간·재촬영으로 해결하며 이유를 기록한다. 마우스/입력 행동 순서를 거꾸로 바꾸지 않는다.
6. 회전 메타데이터를 적용한 실제 화면비로 크롭/스케일하고 UI·자막을 가리지 않도록 한다. 가로 픽셀치만 보고 세로 촬영물을 늘려 찌그러뜨리지 않는다.
7. 레퍼런스의 자막 위치·실제 글자 높이·폰트 느낌/굵기·색·테두리·하이라이팅·줄 수·문구 분할과 등장/퇴장 박자를 재현한다. 출력 해상도에 맞춰 bbox와 실제 글자 높이의 비율을 환산한다. 폰트 크기 숫자만 같게 설정하는 것은 검증이 아니다. 폰트 이름이 불명확하면 유사 폰트와 시각적 차이를 기록한다. 원본이 짧은 문구를 순차 노출하면 새 대사도 같은 단위로 나누며 긴 두 줄 문장으로 바꾸지 않는다. 강조가 없는 원본에 강조를 추가하거나 원본 위치를 임의의 하단 배치로 바꾸지 않는다. 대사만 억지로 가속해 길이를 맞추지 않는다.
8. 최종 전 구간을 시청·청취하고 같은 화면 크기로 맞춘 원본/결과의 훅·데모·CTA 비교 프레임을 저장해 나란히 비교한다. 컷 순서/길이, 자막 bbox/크기, 훅·CTA, 화면/음성 싱크, 원본 소리 잔존, 잘린 말끝을 검수한다.

촬영본 원음 제거는 제품 화면 촬영물에 적용한다. 사용자가 그대로 재사용하도록 선택한 AI 훅 영상은 네이티브 음성과 영상 타이밍을 함께 보존한다. 별도 요청 없이 재더빙하거나 음성을 덮어쓰지 않는다. 해당 shot의 `mute_source_audio`는 false로 기록하고 이유를 남긴다.

## 실행 아티팩트

각 실행 `artifacts/`에 `reference-breakdown.json`, `adaptation-map.json`, `edit-timeline.json`, `content-review.json`을 둔다. 단계 기록은 이 파일들의 URI/해시를 연결한다.

edit-timeline shot 필수값: shot_id, reference_in/out, source_asset_id/hash, source_in/out, output_in/out, speed_segments, mute_source_audio(촬영본=true; 승인된 네이티브 훅=false), crop, transition, subtitles, narration_in/out, hold_seconds, deviation_reason.

속도 구간별 원본 길이/속도의 합과 hold/transition overlap을 반영해 실제 출력 길이를 확인한다. 샘플 프레임만 검토하고 완성영상 전체 검수로 표시하지 않는다. 현재 문서는 실행 규칙이며 이번 작업에서 새 완성 영상을 렌더하지 않았다.
