# 발화형 훅에서 무음 리액션으로

하네스가 반복되는 생성 실패를 바탕으로 훅의 제작 방식을 바꾸고, 전환한 포맷에서 좋은 게시 반응을 확인한 운영 사례다.

## 문제: 말을 시킬수록 훅의 완성도가 흔들렸다

초기에는 AI 인물이 직접 대사를 말하는 훅을 제작했다. 얼굴 일관성, 입 모양과 음성의 불일치, 발화가 끝난 뒤 남는 어색한 구간이 반복됐다. 대사와 움직임을 함께 맞추는 작업이 제작의 병목이 됐다.

## 판단: 발화가 없어도 훅의 역할을 수행할 수 있다

하네스는 발화형 훅을 계속 재생성하는 대신, **노트북을 보고 놀란 뒤 카메라를 바라보는 무음 리액션**으로 제작 방식을 전환했다. 관심을 끄는 메시지는 화면 자막에 맡기고, 제품 사용법은 뒤에 이어지는 실제 Dupy 데모와 내레이션으로 전달했다.

이 전환은 훅이 수행할 역할을 보존하면서, 생성 단계에서 음성과 입 모양을 동시에 맞춰야 하는 요구를 줄인 결정이다. 사용자가 선택한 레퍼런스의 구도·표정·박자를 유지하는 방향으로 실행했다.

## 실행과 결과

선택한 인물 이미지로 리액션 장면을 만들고, 카메라를 바라보는 동작까지 포함했다. 짧은 훅에 맞게 속도를 조정하고 자막을 붙인 뒤 실제 제품 화면·설명·CTA로 이어지는 릴스로 게시했다.

**무음 리액션으로 전환한 포맷의 게시물에서 높은 조회 반응을 확인했다.** 제작 단계의 반복 실패가 포맷 변경으로 이어졌고, 변경한 결과물을 실제 채널에 배포해 반응까지 회수했다는 점이 이 사례의 핵심이다.

## 하네스가 바꾼 것

| 단계 | 이전 | 전환 후 |
|---|---|---|
| 훅 생성 | 인물의 대사·표정·움직임을 함께 생성 | 대사 없이 표정과 행동으로 반응을 전달 |
| 메시지 전달 | 훅 인물의 발화 | 화면 자막, 이후 제품 설명의 내레이션 |
| 품질 검수 | 얼굴·동작과 함께 립싱크 확인 | 리액션·시선·인물 일관성·자막 박자 확인 |
| 제품 설명 | 실제 Dupy 사용 장면 | 실제 Dupy 사용 장면 유지 |

**실패 관측 → 제작 병목 판단 → 포맷 전환 → 실제 제작·게시 → 반응 확인**이 연결된 개선 사례다. 같은 방식의 생성 요청을 반복하는 대신 작업 분담 자체를 바꿨다.

## 근거와 적용 범위

- 제작 과정의 반복 오류, 무음 리액션 제작·속도 조정·자막 결합과 게시 후 반응은 기존 운영 기록을 바탕으로 정리했다.
- 전환 판단을 하네스가 찾았다는 경위는 2026-11-01 운영자의 명시적 정정을 반영했다. 기록 날짜는 사례를 정리한 날짜이며, 새 제작을 실행한 날짜가 아니다.
- 전환한 포맷에서 좋은 반응을 얻었다는 관측과, 무음 전환 하나가 반응 차이의 원인이었다는 인과 주장은 구분한다. 동일 조건 A/B 실험이나 모든 향후 콘텐츠의 성공을 주장하지 않는다.
- 초기 발화형 후보의 품질 문제와, 게시된 서로 다른 영상의 성과 비교는 다른 자료다. 이를 통제된 구버전·신버전 실험으로 합치지 않는다.
- 이 사례는 실제 제작 전략의 개선이다. 자동 코드 패치·고정 평가 세트·자동 승격·복귀 엔진의 구현 완료를 뜻하지 않는다.
- 실제 미디어와 세부 레퍼런스는 비공개로 유지한다. [기존 관측 기록](harness2-round-2026-10-31.md)의 질문형 훅 분류는 철회됐으며, 이 사례와 혼동하지 않는다.
