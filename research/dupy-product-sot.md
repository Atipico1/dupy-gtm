# Dupy 제품 SoT — 제휴 쇼핑 콘텐츠 GTM

기준일: 2026-10-24 KST. 목적: Instagram·Threads 획득 실험과 AI 모델 도입부 제작에서 사용할 제품 사실, 메시지 가설, 검증 경계를 한곳에 둔다. 이 문서는 제품 저장소를 바꾸거나 외부 게시를 승인하지 않는다.

## 1. 지금의 결론

**Dupy는 반응이 컸던 쇼핑 콘텐츠를 참고해, 자신의 상품 자료로 영상과 Threads 글을 만들고 검토·게시까지 관리하는 도구다.** 공개 홈페이지의 현재 포지션은 “콘텐츠 마케팅 작업 공간”, 핵심 헤드라인은 “반응 좋았던 콘텐츠, 이제 내 상품 버전으로”다. 제휴 크리에이터용 실제 Studio 화면이 존재한다.

사용자가 원하는 “손하나 까딱 안 해도 수익화할 수 있는 제휴쇼핑 쇼츠를 만들어준다”는 **도달하고 싶은 컨셉**이다. 현재 확인한 제품은 상품·자료 입력, 생성 비용 승인, 결과 검토, 계정 연결과 게시 판단을 요구한다. 제휴 수수료 발생·매출 귀속·무인 운영을 검증한 증거는 이번 확인에 없다. 따라서 GTM에서는 **제휴 콘텐츠 제작 부담을 줄이는 약속**을 먼저 시험하고, 자동 수익은 제품 사실로 쓰지 않는다.

Higgsfield로 만드는 AI 모델의 첫 3초 훅은 **이번 GTM 광고 소재 제작 방식**이다. 현재 Dupy의 기본 생성 엔진이라는 뜻이 아니다. 확인한 상품 영상 코드 경로는 HeyGen/OpenRouter, Vertex 음성, Hypit 조립을 사용하며, 확인 범위에서 Higgsfield 연동은 발견하지 못했다.

## 3. 타깃: 현재 사실과 GTM 선택

### 제품이 현재 포괄하는 사용자

공개 홈페이지는 특정 제휴 프로그램에 한정하지 않고 상품을 홍보하는 크리에이터·판매자·팀을 포괄한다. Studio에는 제휴 크리에이터 전용 메뉴가 있고, 상품 탐색·소재 찾기·상품 영상·Threads 글·URL to Video·내 영상·소개하는 상품·게시/예약 동선이 노출된다. 메뉴 존재만으로 각 기능의 실제 완료 성공을 증명하지는 않는다.

### 이번 실험의 권장 초기 타깃 — 가설

**쿠팡 파트너스 등 본인 제휴 링크를 이미 갖고 있으며, Instagram 또는 Threads에 상품 콘텐츠를 올리려 하지만 촬영·대본·편집·반복 제작에서 막히는 1인 크리에이터.**

- 준비물과 수익 구조를 이미 이해하므로 제품 제작 경험을 빨리 확인할 수 있다.
- 고객이 맡고 싶은 일은 “이 상품을 소개할 게시물을 계속 만드는 일”이다.
- 시험할 핵심 고통은 출연 부담, 상품을 설명하는 훅 작성, 자료를 영상으로 엮는 시간, 다음 소재 선택이다.
- “아직 제휴 계정도 없는 부업 입문자”는 후속 확장 타깃이다. 현재 흐름으로는 가입·프로그램 승인·본인 링크·상품 자료·게시 계정 등 여러 선행 조건이 생긴다.

이 구분은 고객 인터뷰·실제 전환 데이터로 검증하기 전의 GTM 판단이며, 확인된 고객 분포나 시장 규모가 아니다.

## 4. 핵심 약속과 실제 여정

### 상품 영상

1. 제휴 크리에이터의 상품 영상 화면에서 추천 상품을 보거나 직접 입력한다. 추천 카드에는 원본 콘텐츠와 조회/평소 대비 배수 등이 표시된다.
2. 상품 링크, 상품명·설명, 사용할 사진·영상을 넣는다. 실제 직접 입력 탭은 제품 라벨·용기가 잘 보이는 원본 사진을 함께 요구한다.
3. 제작을 요청한다. 관측한 선택 프로젝트에서는 최대 $12 생성 비용 승인이 표시됐다. 이는 SaaS 구독 가격이나 평균 실제 원가와 같은 수치가 아니다.
4. 코드상 상품 URL 정보를 읽고, 자신의 자료와 선택한 레퍼런스를 묶어 영상 제작을 시작한다. 상품 URL을 읽지 못하면 상품명·설명·자료 보완이 필요할 수 있다.
5. 코드상 상품 원본 확인→기획→상품 근거 검수→필요한 AI 장면 생성→라벨/사용 동작 검수→한국어 내레이션·단어 타이밍→조립/QA로 이어진다. 원본 사진이 없거나 근거·라벨·자료 길이 등이 부적합하면 일시 중지 또는 차단될 수 있다.
6. 완성본을 사람이 검토·수정하고, 연결 계정과 문구·시간을 확인해 게시/예약한다. 이번 점검은 3번 실행 전까지 화면을 관측했으며, 4번 이후는 로컬 코드·문서 근거다.

현재 코드에는 UGC 형식과 제품 중심 Commercial 형식이 있다. UGC는 생성 크리에이터 연출을 허용하되 실제 체험담·입증된 결과를 꾸며내지 않도록 지시한다. Commercial은 생성 인물·얼굴·손을 제외하도록 제한한다. 이는 품질 보장이나 허위 주장이 절대로 나오지 않는다는 보장이 아니다.

### Threads 제휴 글

1. 자신의 쿠팡 제휴 링크를 넣고 상품을 확인한다. UI는 쿠파스 계정 연결 없이 본인 링크로 시작할 수 있다고 안내한다.
2. 선택 사항으로 쿠파스 키를 연결하면 상품 검색·본인 링크 생성 경로를 사용할 수 있도록 로컬 구현돼 있다. 외부 고객 키로 실제 승인·수수료 귀속을 확인한 것은 아니다.
3. 상품 확인 근거와 라이브러리의 관련 레퍼런스로 한국어 초안 3개를 만든다.
4. 링크·고지·상품 사실을 보존하며 수정·복사·저장한다. 계정을 연결하고 검토한 경우 게시 흐름으로 이어진다.

실제 화면은 “잘된 제휴 글을 내 버전으로”, “국내외에서 반응이 컸던 제휴 글을 찾아, 내 상품에 맞는 글 3개”라고 설명한다. 이번에 열린 선택 프로젝트는 레퍼런스/작성자가 각각 0개였다. **이 프로젝트에서 레퍼런스 기반 첫 생성이 바로 가능한지는 별도 확인이 필요하다.** 이 수치를 전체 서비스의 데이터 부재로 일반화하지 않는다.

| “잘 팔리는 상품/검증된 수익 상품 추천” | 공개 반응·구매 경로 분류는 매출 증거가 아님 | ‘반응이 컸던 쇼핑 콘텐츠의 상품’ 정도로 제한 |
| “클릭 한 번/3분/하루 N개/월 N만원” | 현재 전체 여정 시간·완료율·매출 측정 없음 | 실측 전 사용하지 않음 |
| “Higgsfield 기반 Dupy” | 현재 확인 코드에서 연동 발견 못함 | 광고 소재 제작 도구로만 표기 |

공개 랜딩의 최신 문구는 제품이 스스로 내세운 설명이라는 증거다. 그 설명만으로 고객의 실제 성공률·성장률·매출 개선이 입증되지는 않는다.

## 6. 차별점: 사실에서 도출한 방향

1. **탐색과 제작을 잇는다.** 빈 편집기에서 시작하는 대신 공개 반응이 큰 콘텐츠·도입부·전개를 보고 자신의 상품에 적용하도록 설계돼 있다. 조회수는 수익이 아닌 참고 신호다.
2. **같은 상품을 영상과 Threads 글로 확장한다.** 상품 맥락·본인 링크를 중심으로 두 채널의 콘텐츠를 만들 수 있는 방향이다. 두 출력이 단일 요청으로 항상 함께 완성되는지는 검증하지 않았다.
3. **상품 사실과 원본 자료를 검수 지점으로 둔다.** 없는 효능·가격·후기·체험을 생성하지 않도록 코드와 프롬프트에서 제한하고, 제품 라벨·용기 일치 및 자료 길이 문제를 차단하는 경로가 있다.
4. **생성 후 검토와 게시를 연결한다.** 생성물을 곧바로 무인 게시하는 구조를 핵심 약속으로 삼지 않는다.

경쟁사의 동일 기능을 최신 상태로 전수 비교한 결과는 아니다. “유일한”, “최초”, “경쟁사보다 더 높은 매출” 같은 우위 표현의 근거로 사용할 수 없다. 레퍼런스 채널과의 비교는 별도 최신 조사 문서를 따른다.

## 7. GTM 메시지 제안 — 실험용

### 첫 메시지

“소개할 상품은 있는데, 쇼핑 영상 만들기가 막막하다면. 상품 자료로 내 버전의 영상 초안부터 만들어 보세요.”

짧은 약속은 **“내 상품으로 만드는 쇼핑 콘텐츠”** 또는 **“내 제휴 링크로, 영상과 글을 더 쉽게”**다. ‘더 쉽게’의 정도는 첫 사용자 경험에서 검증한다.

### Instagram 첫 3초: AI 모델의 역할

AI 모델은 제품 사용자의 가짜 수익 인증인이 아니라, 제작 문제를 짚고 실제 제품 데모로 넘기는 진행자다.

- 문제 훅 후보: “이 상품 소개 영상, 직접 찍어야 할까요?”
- 행동 훅 후보: “이 상품 자료로 쇼핑 영상부터 만들어볼게요.”
- 이어지는 증거: 실제 상품 링크·원본 사진 입력 → 진행 과정 일부 → 검토 가능한 완성본. 생성 결과를 아직 확인하지 않은 경우 완성본이라고 꾸미지 않는다.
- 광고 소재에서 Higgsfield로 만든 진행자를 쓰더라도, Dupy 결과물이나 실제 이용자 후기와 혼동시키지 않는다. 실제로 쓰지 않은 상품의 사용 경험이나 수익을 말하게 하지 않는다.

### Threads 첫 메시지

“상품은 정했는데 첫 문장이 안 써진다면, 내 제휴 링크로 시작해 보세요. 반응이 컸던 글의 흐름을 참고해 내 상품 초안 3개를 만드는 방식입니다.”

여기서 반응 실험은 ‘수익 자동화’ 관심보다 **상품 콘텐츠를 만드는 구체적 마찰**을 풀어주는 메시지에 우선 둔다. 전환 목표는 링크 클릭만이 아니라 유효한 상품 확인→첫 초안 또는 영상 완료다.

## 8. 미구현으로 단정할 수 없는 것과 실제 검증 공백

### 이번 확인에서 구현·운영 사실로 증명하지 못한 것

- 무인 상품 선택→링크 발급→미디어 확보→쇼츠 생성→무인 게시→수수료 정산까지의 전 과정.
- Dupy 내 실제 제휴 매출·전환·정산 계측과 사용자별 수수료 귀속.
- Higgsfield가 Dupy의 현재 생성 경로로 통합돼 있다는 사실.
- 새 외부 사용자의 가입/무료 플랜/크레딧 차감/첫 생성/결제 전 과정 성공.
- Meta 심사 종료·외부 고객 권한 승인, 각 게시 실행기의 현재 상태.
- 상품·카테고리 전반의 완성률, 제작 시간, 라벨 일치율, 한국어 음성 품질과 반복 재생 품질.

위 항목은 “이번에 증거를 확보하지 못했다”는 뜻이다. 저장소 전체의 부재나 현재 운영 미완성을 확정한 것은 아니다.

### 관측된 마찰과 우선 확인할 일

| 마찰/리스크 | 왜 중요한가 | 다음 확인 결과 |
|---|---|---|
| 원본 제품 사진 필수 | 제휴 상품 선택만으로 시작할 수 있다는 기대와 다름 | 신규 사용자가 권한 있는 사진을 쉽게 준비하는지, 실제 첫 제작 성공 여부 |
| 선택 프로젝트 Threads 레퍼런스 0개 | 핵심 약속의 첫 체험이 막힐 수 있음 | 새 계정/프로젝트에서 사용할 레퍼런스 공급과 매칭 실패 시 동작 |
| 무료 크레딧 안내와 $12 생성 승인 | 비용·과금 단위를 혼동할 수 있음 | 신규 사용자가 보는 승인 문구, 실제 차감·실패 환급·추가 비용 여부 |
| 반응 지표의 시점 차이 | 추천 데이터의 최신성 기대가 어긋날 수 있음 | UI 표시대로 Instagram은 10월 5일 수집값, YouTube는 카드별 확인일. 최신 인기라고 부르기 전 갱신 시각 확인 |
| Meta 보호 지침 | 심사 동선 변경이 현재 사용자 제약을 침해할 수 있음 | `dupy/AGENTS.md`는 실제 종료 증거 전 관련 변경 금지. GTM 문서 작업은 제품을 변경하지 않음 |
| 로컬·문서·배포 리비전 불일치 | 오래된 설명이나 미배포 코드를 기능 사실로 오인 | API/worker/web 리비전과 실제 완성본 한 건을 대조 |
| AI 진행자와 실제 후기 혼동 | 제품 신뢰와 데모 해석에 영향 | 진행자 연출·실제 제품 화면·사용자 증거를 명확히 구분한 광고 검수 |

가장 먼저 검증할 단위는 **실제 고객 유형 한 명 + 권한 있는 상품 자료 하나 + 본인 제휴 링크 하나로, 첫 결과물이 게시 검토 가능한 상태까지 도달하는가**다. 그 뒤 실제 게시·추적 링크·정산 자료를 연결해야 수익화 주장의 근거가 생긴다. 이 검증을 이번 작업에서 실행하지 않았다.

## 9. 가격 — 공개 UI 관측값

2026-10-24 [공식 요금 페이지](https://dupy.app/pricing) 기준. 플랜 가격·완료량은 사이트의 안내를 전사한 것이며 결제/원가/생성 성공률을 직접 검증한 수치가 아니다.

| 플랜 | 월 가격(VAT 포함) | 월 크레딧 | 사이트가 표시한 대안별 최대량 |
|---|---:|---:|---|
| Free | 무료 | 100 | 쇼핑쇼츠 5개 또는 텍스트 초안 15개 |
| Starter | 29,900원 | 1,000 | 쇼핑쇼츠 50개 또는 텍스트 초안 150개 |
| Creator | 49,900원 | 2,000 | 쇼핑쇼츠 100개 또는 텍스트 초안 300개 |

공개 표는 쇼핑쇼츠 1개=20크레딧, 텍스트 초안 3개=20크레딧으로 안내한다. 영상과 글의 양을 동시에 전부 제공한다는 뜻이 아니다. 가격은 변경될 수 있으므로 외부 소재 제작일에 다시 확인한다.
